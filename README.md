# FOC 三相无刷驱动器 — 设计文档

> 基于 STM32G473RC 的三相永磁同步电机 (PMSM) 磁场定向控制 (FOC) 驱动器
> 设计目标:高侧/低侧分立的 N-MOS 三相桥 + 半桥栅极驱动 + I2C 电流/功率监测

---

## 1. 项目概述

本项目实现一套完整的 FOC 电机驱动器软硬件方案,面向中小功率 PMSM / BLDC(BLDC 通过梯形波/正弦波兼容)。系统以 **STM32G473RC** 为主控,使用 **3 路 UCC27211** 半桥栅极驱动器驱动 **6 颗 070N10NS** N-MOSFET 组成三相逆变桥,电流/功率采样采用 **INA226**。

软件框架已在此仓库中初步落地 [`software/FOCTestPrj/`](software/FOCTestPrj/),
核心为 `FOCMotor`(FOC 算法)、`FOCDriver`(PWM/驱动抽象)、`FOCSensor`(角度/电流传感抽象)、`PIDController`(PID) 的可移植分层结构。

**本文档与硬件设计、软件框架同步维护**,本文档中 `[待定]` 标记的项需在打板/调试前确认。

### 系统主要指标

| 项目 | 指标 | 备注 |
|---|---|---|
| 母线电压 Vbus | 12 V ~ 48 V (目标)[待定] | 受 MOS/驱动耐压限制 |
| 额定电流 | ≤ 60 A `[待定]` | 受散热与相电流分流/INA240A2 量程 |
| 峰值电流 | ≤ 70 A | 受 070N10NS 极限,需留裕量 |
| PWM 频率 | 20 kHz ~ 40 kHz | STM32G4 高级定时器 |
| 电流环带宽 | ≥ 10 kHz | 硬件需要 µs 级同步采样 |
| 通讯 | I2C (INA226)、UART/USART、SWD、CAN | |

## 2. 主要器件选型

### 2.1 主控 MCU — STM32G473RC (LQFP64 / UFQFPN)

选用理由(STM32G4 系列是 ST 面向电机控制的专用系列):

- **Cortex-M4F @ 170 MHz**,数学能力足以运行 FOC 算法(Clarke/Park/PID)。
- **高级定时器 TIM1 / TIM8**:6 通道互补 PWM,死区插入,再生电流/重复计数器,可直接硬件产生三相六路 PWM。
- **5 路 ADC** 中多路支持与定时器事件对齐的**注入/规则转换**,用于 PWM 中心对齐的关键点电流采样。
- **片上 6 × 运算放大器 (OPA) + 5 × 比较器 (COMP) + 2 × DAC**:
  - 运放可直接放大分流电阻电压作为相电流采样前端;
  - 比较器可实现**硬件快速过流保护 (OCP)**(ns 级,不打中断时也能关断 PWM)。
- 内部提供丰富外设(SPI/I2C/UART),便于扩展。

> 注:既有代码工程基于 STM32H743 编写(`software/FOCTestPrj/mcu/` 下为 H743 的 `.ioc`/启动文件),**需按 G473RC 重新生成外设工程**并移植上层 `FOCMotor/FOCDriver/FOCSensor` 抽象,见 §7。

### 2.2 栅极驱动器 — UCC27211 (×3)

UCC27211 为 120 V、4 A 峰值输出的**高频半桥栅极驱动器**,非常适合隔离/非隔离高低侧应用,关键特性:

| 参数 | 值 |
|---|---|
| 输入电源电压 | 8 V ~ 110 V (逻辑侧 VDD 需 5 V~20 V) |
| 高/低侧输出峰值电流 | 4 A / 4 A |
| 传播延迟 | 典型 ~18 ns |
| 开关频率 | 最高 ~2 MHz(满足 40 kHz 后仍余量充足) |
| 逻辑输入 | 兼容 TTL/CMOS,输入带下拉,防上电误触发 |
| 输入类型 | 两输入 (HI、LI) 独立控制高/低侧 |

**三相桥拓扑**:3 个半桥 = 需要 **3 × UCC27211**,每相 1 颗。

- 每相高侧 UCC27211 的 **HB-HS 自举**:高侧栅极供电来自自举电容,需在 HS 与 HB 间放置 ≥ 100 nF 自举电容 + 自举二极管。在 20~40 kHz 下自举电容按 **1 µF 数量级**选择保证高侧导通时间内的电荷支撑。
- **HS (自举地) 设计注意**:UCC27211 的高侧输出以 HS 为参考,须保证 HS 电压摆动不超过逻辑地允许范围;必要时在 PCB 布线上给 HS 加 RC 吸收以抑制 di/dt 产生的振铃/负过冲。
- 每路输出串联 **栅极电阻 Rg(典型 1 Ω ~ 10 Ω)**,用于限制 dV/dt、抑制开关振铃。

> 说明:UCC27211 每颗只驱动一个半桥(1 高 1 低),与「6 个 MOS / 3 相」一一对应,done.

### 2.3 功率 MOS — 070N10NS (×6)

| 参数 (典型值,以数据手册为准) | 值 |
|---|---|
| VDS | 100 V |
| ID (连续) | 70 A @ 25 °C |
| RDS(on) | ~7 mΩ (VGS=10 V) `[复核]` |
| VGS(th) | ~1.4 V ~ 2.4 V |
| 封装 | TO-252 (DPAK) 等 |

- 三相桥上下桥臂各 3 颗,共 **6 颗**,成 3 相半桥。
- **栅极驱动电压**:070N10NS 需要 VGS 尽量高以获得低 RDS(on);UCC27211 的 VDD 建议取 **10 V~12 V**,由板上独立栅极供电轨 (VDRV) 提供。
- **续流**:利用 MOS 体二极管 + 必要时并联合适的 RC snubber 抑制开关尖峰;若需更低损耗可外挂肖特基(小型电机通常省略)。
- **散热**:70 A 为极限值,连续大电流必须配合散热器与风道;板载电流预算以 `[待定]` 明确。

### 2.4 母线电流/功率监测 — INA226 (×1)

16 位、I2C 接口、高精度直流电流/功率监测芯片,**负责母线遥测**,不承担相电流闭环:

| 参数 (典型) | 值 |
|---|---|
| 总线电压测量范围 | 0 ~ 36 V (母线) |
| 分流电压测量 (差分) | ±81.92 mV |
| 分辨率 | 16 位 (电流),支持可编程量程/转换时间 |
| 转换时间 (可编程) | 140 µs ~ 8.244 ms |
| I2C 地址 | 0x40 ~ 0x4F (A0/A1) |
| 告警输出 | ALERT 引脚 (可编程阈值,电流/功率/欠压等) |

**角色定位(母线专用)**:

1. **母线电流 / 母线电压 / 功率** 遥测与运行统计;
2. 通过 ALERT 引脚实现**软件可配置的过流/过功率快速告警**;
3. 反推系统级功率、估算效率。

> 因 INA226 为直流平均式、单次转换毫秒级,不做 PWM 同步瞬时采样;**相电流闭环交给 INA240A2 (§2.5)**。

### 2.5 相电流采样 — INA240A2 (×3)

TI 专为电机控制设计的**高带宽、双向、带 PWM 抗误差**电流检测放大器,直接用于三相 FOC 电流环采样:

| 参数 (典型) | 值 |
|---|---|
| 供电 | 2.7 V ~ 5.5 V |
| 输入共模电压范围 | -4 V ~ 80 V |
| 放大增益 (A2) | 40 V/V (±0.05% 增益误差 `[复核]`) |
| 双向测量 | 支持 (REF 引脚设定零电流点) |
| PWM 抗误差 | 增强型,可抑制电机 PWM 共模瞬变 |
| 传播延迟 | ~300 ns 级 |
| 输入失调电压 | 典型 ~25 µV |
| 封装 | 小型 SOT / 类比封装 |

**在三相桥中的作用(每相 1 颗,共 3 颗)**:

- 放在母线/电机侧分流电阻两端(可**高边**或**低边**,宽共模范围使布点灵活),放大相电流到 ADC 可测范围。
- **高带宽 + 短传播延迟 + PWM 抗误差**,可做到与 TIM1 载波对齐的**接近实时的相电流采样**,满足 >10 kHz 电流环需求。
- 差分开尔文连接分流电阻,输出经 RC 滤波后送 MCU ADC 或片上运放。

> 三颗 INA240A2 支持**三相电流同时测量**(也可只采两相、第三相由 KCL 推算),详见 §5。

## 4. 硬件电路设计要点

### 4.1 电源树

```
输入电源 (Vbus, 12~24V) ──► [反接保护] ──► 母线电容 (电解+陶瓷)
        │
        ├─► DC-DC 5 V ──► LDO 3.3 V ──► MCU 逻辑
        └─► DC-DC/稳压 10~12 V (VDRV, 栅极驱动电源) ──► UCC27211 VDD / 自举
```

- **母线电容**:需足够容量支撑 PWM 开关电流脉动,电解电容 + 高频陶瓷电容并联。
- **栅极驱动电源 VDRV** 独立于逻辑电源,避免开关噪声耦合到模拟/逻辑地。
- **地平面**:功率地 (PGND) 与 逻辑地/模拟地 (AGND) 单点连接;相电流分流与母线分流的地线各自独立走回母线负极,避免采样被开关电流污染(PGND 与采样地分离,见 §5)。

### 4.2 栅极驱动与死区

- TIM1/TIM8 输出互补 PWM,配置**死区插入**;死区时间典型 **100 ns ~ 500 ns** `[按 MOS 开关速度调整]`,防止桥臂直通。
- UCC27211 输入 HI/LI 直接由定时器互补输出驱动;上电期间 MCU 不复位配置时,输入下拉保证 MOS 截止。
- **上/下电顺序**:先使能栅极供电、再使能 PWM;异常时建议通过 `FOCDriver::disable()` 切断 PWM 并封锁高侧。

### 4.3 保护(见 §6)

- 硬件快速过流 (COMP + 取样电阻)
- INA226 ALERT 过流/过功率
- 母线欠压/过压软件保护
- 温度保护 (若板载 NTC) `[可能项]`

## 5. 电流采样策略

FOC 电流环需要 **IK 时刻的瞬时相电流**,这里采用「**相电流 INA240A2 + 母线 INA226**」的组合分工。

### 相电流(电流环主控)—— INA240A2 ×3
- 每相分流电阻(如 5 mΩ~10 mΩ `[待定]`)两端各接一颗 INA240A2,放大后送 MCU ADC。
- 利用 TIM1**换向重复计数 + ADC 触发**,在 PWM 载波谷/峰(中心)对齐启动转换,避开开关瞬态,采样稳定的相电流。
- **宽共模 (-4~80 V)+ PWM 抗误差 + 短延迟**(~300 ns)满足 >10 kHz 电流环带宽。
- 三颗支持三相同时测量;也可只采两相、第三相由 KCL(ia+ib+ic≈0)推算以省一路成本 `[可选]`。
- 建议在 INA240A2 输出与 ADC 之间加 RC 滤波,并差分布线。

### 母线电流/功率监测 —— INA226
- 分流电阻放在 **母线低边**,INA226 差分测量 Vbus(0~36 V)与母线分流电压。
- 用于:母线电流遥测、功率/效率估算、过流/过功率告警、运行状态监控。
- **注意**:毫秒级转换,只反映直流/低频平均值,**不承担** PWM 同步瞬时采样,不做电流环主控。

### 采样回路的信号完整性
- 相电流与母线分流电阻均采用四线制(开尔文)连接,采样走线各自差分并尽量短。
- 屏蔽/远离开关节点 (HS 振铃);采样地与功率地单点汇流。
- ADC 参考电压用低噪声基准,避免与逻辑电源同源耦合。
- INA240A2 输出低通截止频率按电流环带宽要求设定(`[待定]`),兼顾降噪与相移。

## 6. 保护功能设计

| 保护 | 实现 | 响应 |
|---|---|---|
| 过流(硬件级) | STM32G4 COMP 比较分流电压,输出到定时器 **刹车(BRK)** | ns~µs 级 PWM 关断 |
| 过流/过功率(可编程) | INA226 ALERT → MCU EXTI | 中断处理软件关断 |
| 母线欠压/过压 | ADC 采样 Vbus,软件阈值 | 停止使能/告警 |
| 直通/死区失效 | 死区插入 + 调试阶段电流钳验证 | 硬件规避 + 测试 |
| 过温 | (可选) NTC → ADC | 降额/停机 |

> 尤其推荐把 **COMP → TIM 刹车** 作为主保护:即使 MCU 主循环或电流环异常,也能在定时器硬件层面快速关断三相 PWM,防止上/下桥直通烧毁器件。

## 7. 软件开发框架

仓库已有 `software/FOCTestPrj/`。移植到 G473RC 的固件分层建议:

```
App/
  foc.h  foc.cpp          ├─ FOCMotor    : 算法编排 (loopFOC/setVelocity/...)
  foc_driver.h/.cpp       ├─ FOCDriver   : setPWMDuty / setPhaseVoltage / PWM 频率
  foc_utils.h/.cpp        ├─ MotorMath   : Clarke/Park/逆变换
  sensor.h  sensor.cpp    ├─ FOCSensor   : 角度(编码器/HALL)抽象
  pid.h     pid.cpp       └─ PIDController
mcu/                      └─ STM32G473RC HAL 工程 (TIM1/8, ADC+OPA+COMP, I2C, UART)
```

Map 到硬件的职责:

- **FOCDriver** → 封装 TIM1/TIM8 互补 PWM、死区、`enable()/disable()`(含 BRK 状态管理)、`setPhaseVoltage(Ud,Uq,θ)`。
- **FOCSensor** → 接入编码器/HALL 角度与转速;相电流反馈由 3× INA240A2 → ADC 提供(或经片上运放)。
- **INA240A2 采集** → 三路 ADC 同步采样,换算相电流,供 Clarke/Park 变换。
- **INA226 驱动** → I2C 读写寄存器(校准值 Config→Shunt→Bus→Power),提供母线电流/电压/功率与 ALERT 回调。
- **PIDController** → 电流环、速度环复用。

> 现有 `.ioc` 为 H743,移植 H743→G473RC 时注意外设差异(TIM1/8 存在、ADC/OPA/COMP 数量、时钟树需由 168 MHz 核调整),建议直接基于 HAL 从 `STM32CubeMX` 重新生成外设底座,上层抽象保持不变。
