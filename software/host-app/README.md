# FOC Studio（上位机）

基于 **Vue 3 + TypeScript + Tauri 2** 的电机调试桌面工作台。Rust 后端复用 [`../foc-wire`](../foc-wire) 的 v2 帧协议，通过加密无线桥接与 STM32G473 FOC 固件交互。

---

## 运行模式对比

| 能力 | 浏览器预览（`npm run dev`） | 桌面模拟器（Tauri） | 真实设备（C3 加密桥接） |
|---|---|---|---|
| 实时遥测与多通道曲线 | 模拟数据 | 模拟数据 | STM32 20 Hz 遥测 |
| 43 项参数读写 / JSON 导入导出 | 仅会话内存 | 仅会话内存 | 读写 STM32 RAM / Flash |
| 控制权租约与电流/速度/开环命令 | 模拟状态机 | 模拟状态机 | 经加密桥接下发 STM32 |
| 串口扫描与硬件连接 | 不支持 | 仅扫描 | 支持（需桥接 `secure=1`） |
| 自动整定（Auto-Tune） | 不支持 | 仅模拟进度，非真实辨识 | 由 STM32 执行真实辨识 |
| 遥测录制与 CSV 导出 | 浏览器下载 | 保存至系统下载目录 | 保存至系统下载目录 |
| 运行日志自动落盘 | 不写本机文件（仅内存列表 + 手动导出） | 自动保存 UTF-8 日志文件 | 自动保存 UTF-8 日志文件 |

> 浏览器与桌面模拟器仅用于界面和会话逻辑验证，**不是**包含真实机械动力学的物理仿真（物理仿真请见 [`../foc-sim/README.md`](../foc-sim/README.md)）。

## 界面与功能概览

- **运行监控**：机械转速（rpm）、三相电流、母线电压、温度卡片；20 Hz 波形曲线（相电流 / dq 电流 / 转速 / 母线电压 / 温度，支持暂停与数据表切换）；控制状态、故障位解析与清除故障。
- **参数配置**：43 项固件参数分组编辑、逐项非原子写入并读回、JSON 配置导入/导出，以及设备端加载、恢复默认、出厂重置与保存到持久存储。
- **自动整定**：`autotune start / stop / status` 命令入口与状态展示（需要桌面端、设备就绪并取得控制权）。
- **数据记录**：主机端遥测录制（单次上限 12,000 帧）与 CSV 导出。
- **右侧栏**：连接与控制权管理、设备身份与链路时效、运行日志面板（含自动保存状态、打开日志目录、导出当前列表）。
- **底部控制栏**：模式选择（电流 / 速度 / 开环）、目标值下发、带二次确认的使能按钮与一键停用。

## 快速开始与构建

以下命令均在 `software/host-app` 目录执行。

**环境要求：**
- 浏览器预览：Node.js / npm
- 桌面模式与打包：额外需要 Rust MSVC 工具链、Windows C++ 构建工具和 WebView2

```powershell
# 1. 安装前端依赖
npm ci

# 2. 启动运行（二选一）
npm run dev              # 浏览器预览模式（http://127.0.0.1:1420）
npm run tauri -- dev     # Tauri 桌面开发模式

# 3. 检查与测试
npm run build            # vue-tsc 类型检查 + Vite 前端生产构建
cargo test --locked --workspace
cargo clippy --locked --workspace --all-targets -- -D warnings

# 4. 构建桌面可执行程序（不生成安装器）
npm run tauri -- build --no-bundle
```

> 前端构建通过不等于桌面打包成功，也不代表真实硬件联调已验证。

## 真实设备连接与安全操作流程

真实串口路径对接 [`../esp32-pc-bridge`](../esp32-pc-bridge/README.md) 的 `pc` 固件（v2 加密桥接），不兼容旧版明文 v1 接收器或直接 UART ASCII 终端。`host-transport` 中的 TCP/UDP/HID/BLE 适配器尚未接入当前 FOC 会话。

**标准操作顺序：**

1. **扫描并连接**：选择「C3 加密桥接」，刷新并选择串口后点击「连接」。后端会执行桥接握手（校验 `secure=1`）及 STM32 身份、能力校验，并读取当前参数。
2. **获取控制权**：点击「获取控制权」（仅申请租约，**不会**使能电机）。前端定时续约心跳；链路超时或遥测过期将触发失联保护与停用请求。
3. **设定目标并使能**：在底部控制栏选择模式并下发目标值，确认电机安全固定与限流电源就绪后再点击使能并确认弹窗。
4. **参数修改与保存**：仅在**设备就绪、取得控制权且电机空闲**时开放写入和持久化操作；写入 RAM 与保存到设备 Flash 是两个独立动作。
5. **停用与释放**：测试结束后点击「停用」并释放控制权。**界面上的「停用」与「停止整定」均为软件请求，不能替代硬件急停。**

## 桌面运行日志

桌面端启动后会自动开启 UTF-8 运行日志，无需手动配置：

- **文件位置**：优先在可执行文件同级的 `logs/` 目录下创建本次运行独占的日志文件 `foc-studio-YYYYMMDD-HHMMSS.mmm-<pid>.log`。若程序目录不可写，自动回退到应用日志目录（Windows 下为 `%LOCALAPPDATA%\dev.focstudio.desktop\logs`）。两处均不可写时在日志区显示告警，不阻断工作台使用。
- **记录内容**：包含毫秒时间戳、时区、级别和来源，记录启动/正常退出、连接与端口扫描、命令及应答、参数写入值、录制与导出操作及报错信息。原始 20 Hz 遥测帧**不写入**运行日志（需通过「数据记录」导出 CSV）。
- **界面操作**：点击侧栏 **运行日志 → 打开日志目录** 可打开实际目录（悬停按钮显示完整路径）；支持将当前列表手动导出为 `.log`。侧栏仅显示最近 200 条，清空列表不会删除磁盘上的日志文件；历史日志文件不会自动清理。
- **浏览器预览差异**：浏览器模式仅保留内存中的日志列表并支持手动下载，不自动写入本机文件。

## 目录结构

| 路径 | 说明 |
|---|---|
| [`src/`](src) | Vue 3 界面、遥测图表（`TelemetryChart.vue`）、控制栏（`ControlBar.vue`）、日志 composable（`useRunLog.ts`）与浏览器模拟器（`api.ts`） |
| [`src-tauri/`](src-tauri) | Tauri 桌面命令、串口扫描、文件导出（`lib.rs`）与自动运行日志（`run_log.rs`） |
| [`crates/device-foc/`](crates/device-foc) | FOC 设备模型、43 项参数描述、v2 会话状态机与桌面模拟器 |
| [`crates/host-transport/`](crates/host-transport) | 串口及通用传输适配层 |
| [`crates/host-core/`](crates/host-core) | 通用参数与模拟器基础库 |

`node_modules/`、`target/`、`dist/`、`src-tauri/gen/` 与本地环境文件不纳入版本控制。目前尚未完成整机实板联调验收。
